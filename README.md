# 罗汉到家 - 上门按摩 MVP

一个基于 React 与 Vite 构建的上门按摩预约前端原型。

## 功能

- 按距离排序的附近技师列表与搜索
- 技师详情及服务选择
- 未来三天的日期和服务时段预约
- 下单后的订单任务加载页
- 订单详情与状态推进：待接单、已接单、服务中、已完成
- 使用 LocalStorage 保存当前订单

## 本地启动

```bash
pnpm install
pnpm run dev
```

浏览器打开终端中显示的本地地址，通常为 `http://localhost:5173`。

## 技术栈

React、Vite、React Router、CSS、LocalStorage。
